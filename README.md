# GG Produzioni

Sito statico per GG Produzioni. La home page è `index.html`; non richiede build o dipendenze JavaScript.

## Media

I quattro filmati usati dal sito sono versioni H.264 MP4 ottimizzate per la riproduzione web, con fast-start. Le copie originali ad alto bitrate restano locali e sono escluse dal repository.

## Pubblicazione

Il sito può essere servito da un hosting statico dalla root del repository. La pubblicazione tramite GitHub Pages non viene attivata da questo repository automaticamente.
